# BILIM TEST — №49 мектеп

Supabase-пен байланысуға арналған онлайн тестілеу платформасының бастапқы нұсқасы.

1. `index.html` файлын GitHub репозиторийінің түбіріне жүктеңіз.
2. Сайттағы «Алғашқы баптау» бөлімінде Supabase Project URL және publishable/anon public key енгізіңіз.
3. Мұғалімдер Supabase Authentication аккаунтымен кіреді; әр мұғалімге `profiles` кестесінде өз UID-імен `role=teacher` профилі қажет.
4. Vercel арқылы жариялаңыз.

**Қауіпсіздік:** браузерге `service_role` немесе `secret` key енгізбеңіз. Бұл MVP-ді мектепте кеңінен қолданар алдында RLS және RPC функцияларына толық қауіпсіздік аудиті қажет.
